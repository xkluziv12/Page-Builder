name: Joomla template default
description: The default Joomla template selection and its required visual treatment across this project.
---

For STS Joomla sections and artifacts, the user-selected default label is **TOP LOGO 2026 (TESTING TIME)**. When shown as a choice, make it conspicuous in red. Do not apply this setting to non-Joomla platforms or unrelated brands.

**Why:** the user specified this as the project-wide Joomla default. A June 2026 Joomla admin audit recorded `CLEAN TOP 2026` and `TOP LOGO 2026` as dropdown entries, but did not record `TOP LOGO 2026 (TESTING TIME)`. The current live dropdown still needs verification.

**How to apply:** use the selected label consistently in STS Joomla template selectors and generated Joomla-related artifacts, but verify the exact selectable CMS value before instructing operators to choose it. Do not apply it to non-Joomla platforms.
