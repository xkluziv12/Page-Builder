# Bake-Off (artifacts/bake-off)

A static Vite/React viewer for an LLM "bake-off": it renders leaderboards
comparing how different models (Claude, GPT, Gemini, Grok, ...) generate a
local-business landing page from the same brief. This directory is **only the
viewer** — a read-only presentation layer over pre-generated JSON result
files. The generation harness (live model calls, screenshot rendering,
scoring) lives elsewhere in the workspace (see commit history references to
`scripts/src/bakeoff/`) and is out of scope for this CLAUDE.md.

## Hard rules

- **Google Drive is out of scope.** Do not add, wire up, or reach for any
  Google Drive integration from this artifact.
- **No secrets.** Never add API keys, tokens, or credentials to this
  directory (viewer code, `src/data/*.json`, or `public/`). This is a static
  frontend bundle — anything committed here is publicly servable.
- **Preserve model-agnostic evaluation.** A past bug had a Claude-identity
  gate skewing results (fixed in commit `71d27be`, "neutralize the
  Claude-identity gate"). Any change touching scoring, prompts, or
  result-shaping in this viewer must keep all models evaluated under
  identical, non-favoring logic. Don't special-case any provider.
- **Preserve saved-render integrity.** `screenshot` / `transcriptPath` /
  `costEstimate.basis` fields in `src/data/results.json` are real captured
  evidence (rendered screenshots, per-turn transcripts, measured vs.
  estimated token costs — see `types.ts`). Don't fabricate, backfill, or
  silently paper over missing values (e.g. a model that legitimately errored
  should stay `status: "error"` with no screenshot, not be coaxed into a
  fake pass — see commit `2c4ed41`: "that non-compliance IS the finding, not
  a bug — never coax one model to rescue its cell").
- **Do not touch Mission Control, Page Terminal, the API server, or files
  outside this directory.** This artifact is independently deployed
  (`.replit-artifact/artifact.toml`, path `/bake-off/`, port 23464). Scope
  all edits to `artifacts/bake-off/`.

## Stack

- Vite + React 18 + TypeScript, Tailwind CSS, shadcn/ui (Radix primitives
  under `src/components/ui/`), wouter for routing, TanStack Query (present
  but this app is fully static — no live fetching), recharts for charts.
- Part of a pnpm workspace (uses `catalog:` versions and
  `workspace:*` deps like `@workspace/api-client-react`); `tsconfig.json`
  extends `../../tsconfig.base.json`.
- `vite.config.ts` requires `PORT` and `BASE_PATH` env vars to be set (throws
  otherwise) — matches the Replit artifact service config
  (`.replit-artifact/artifact.toml`: `PORT=23464`, `BASE_PATH=/bake-off/`).

## File map

- `src/App.tsx` — routes: `/` (leaderboard), `/portland-review` (static GMB
  schema reference, no LLM calls), `/model/:datasetId/:scenarioId/:id`
  (model detail).
- `src/contexts/dataset-context.tsx` + `src/data/datasets.ts` — the dataset
  switcher. `DATASETS` is a hardcoded array wrapping the JSON files below;
  add a new run by adding a new entry here, not by mutating an old one.
- `src/data/results.json` — **gitignored**, generated by the external
  harness, present only in the local working copy. Treat as the live/current
  run; regenerating it is outside this artifact's scope.
- `src/data/old-bakeoff.json`, `src/data/produce.json`,
  `src/data/portland-review.json` — committed, static archival/reference
  datasets.
- `src/data/results.prior-*.json` — timestamped backup snapshots left over
  from prior local reruns (safety copies before overwriting `results.json`).
  Historical clutter, not wired into the app; leave alone unless asked to
  clean up.
- `src/types.ts` — the `BakeoffResults` / `ModelResult` / `ModelScores`
  shape shared with the harness. If the harness's output shape changes, this
  is the contract to update to keep the viewer in sync.
- `src/pages/dashboard.tsx` — leaderboard, sorts by `scores.composite`
  descending with errored models pushed to the bottom.
- `src/pages/model-detail.tsx` — per-model tabs (HTML, schema, checker
  report, link audit, visual match, cost/transcript).
- `public/screenshots/`, `public/transcripts/` — committed rendered
  evidence referenced by `results.json`/`old-bakeoff.json` via relative
  paths under `public/`.

## Known evaluation / source-of-truth lessons (from git history)

- Visual scoring: raw token/CSS overlap was a weak proxy (scored 4-7/100
  regardless of real similarity). It was replaced with actual rendered
  screenshots + perceptual diff + vision-LLM judge (`visualPixel`,
  `visualLlm` in `ModelScores`), with the old proxy kept only as
  `visualTokens` for transparency. Don't reintroduce a scoring path that
  only compares source tokens as if it were "visual."
- Cost figures: prefer `costEstimate.basis` reflecting *measured* provider
  token usage over character-based estimates; `usage` holds real
  provider-reported token counts when captured. Don't overwrite a measured
  cost with an estimate.
- A model that refuses/fails a required step (e.g. a mandated live web
  fetch) should surface as an honest `status: "error"`, not be silently
  retried until it passes or backfilled with another model's output. Errors
  in the data are signal, not noise.
- `results.json` is intentionally gitignored (regenerated by the harness);
  don't try to "fix" that by force-adding it or committing a stale copy.

## Verification (safe, local-only, no external services)

Run from this directory:

```
pnpm install                 # only if node_modules is missing/stale
pnpm run typecheck            # tsc --noEmit, no dev server needed
pnpm run build                 # vite build → dist/public, fully local
```

`pnpm run dev` / `pnpm run serve` start a local Vite dev/preview server —
both require `PORT` and `BASE_PATH` env vars (see `.replit-artifact/artifact.toml`
for the values this artifact is deployed with: `PORT=23464`,
`BASE_PATH=/bake-off/`) and bind to `0.0.0.0`; they don't reach out to any
external service since all data is static JSON under `src/data/`.
