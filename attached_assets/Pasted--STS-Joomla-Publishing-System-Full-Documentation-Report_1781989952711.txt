## STEP 15 — NAMING CONVENTIONS & MENU TREE

**State menus:** Named `[State] Service Areas` or `[State] Service Locations`.
**City pages within state menus:** Direct children (Parent Item = Menu Item Root).
**Menu item alias:** `[city]-[2-letter-state]` → `billings-mt`, `phoenix-az`, etc.
**Article alias:** Typically just the city name → `billings` (NOT `billings-mt`).

> ⚠️ **Menu alias ≠ Article alias.** The URL `/billings-mt` comes from the MENU ITEM alias, not the article alias. The article alias `billings` would produce `/billings` if accessed directly by Joomla's article routing, but the menu item route takes precedence and generates `/billings-mt`.

**Creating a NEW city page workflow (not performed — documentation only):**
1. Create a new Article: Content → Articles → New; set Title, Alias (city only), Category = "Areas of Service"; paste HTML content; set Meta Description in Publishing tab; Save.
2. Create a new Menu Item: Menus → [State] Service Areas → New; set Menu Title (City, ST), Alias (city-st), Menu Item Type = Single Article, Select Article (link to new article), Template Style (CLEAN TOP 2026 or default), Status = Published; then set tabs; Save.

**Editing an EXISTING page:** Find via search or state-filter, open menu item for meta/page settings, use "Edit" button to open article editor.

## STEP 16 — IMAGE URL FORMAT (Root-Relative vs Absolute)

**Observed on live /billings-mt page source:**

```
/images/STS_logo_full_horz_green_cmyk.jpg             ← root-relative (no domain)
/images/Industries-We-Serve-2.png                     ← root-relative
https://www.stselectronicrecyclinginc.com/images/...  ← absolute
```

**In article HTML content:** Links use relative paths WITHOUT a leading slash:
```html
href="97-recyclable-electronics/317-computer-recycling"
```
(Joomla SEF routing resolves these from the site root.)

**Verdict:** Root-relative paths (`/images/...`) **DO work** — Joomla does not break them. Both `/images/...` and `https://www.stselectronicrecyclinginc.com/images/...` are valid. However, for automating image URLs in the HTML content body, using the absolute `https://www.stselectronicrecyclinginc.com/images/[path]` is safest for portability and to avoid any CDN/multisite edge cases.

## STEP 17 — ADDITIONAL AUTOMATION KNOWLEDGE

1. **Article ID is critical.** The menu item references the article by ID (`&id=107`). When automating a new page, you must first create the article, capture its ID, then create the menu item referencing that ID.

2. **Two separate "Meta Description" fields exist.** There is one in the Menu Item → Metadata tab (empty, unused) AND one in the Article → Publishing tab (populated, used). The live `<meta name="description">` comes from the **article-level** field. Always write to the article Publishing tab.

3. **The `<title>` tag is not set via "Browser Page Title."** For Billings, the Browser Page Title field is empty, yet the `<title>` is "Billings Electronics Recycling | STS Electronic Recycling". This custom title is being set elsewhere — likely by a Joomla SEO plugin (sh404SEF, OSMeta, or similar) or the Helix template. An automation must account for this; simply filling "Browser Page Title" in the Page Display tab may not be sufficient.

4. **Session check-in:** If a menu item or article is opened but not saved/closed cleanly, Joomla marks it as checked out (lock icon appears in list). Another editor cannot open it. Automation must always Close or Save & Close properly.

5. **The article editor is a plain textarea (editor=none).** HTML is entered/replaced directly. No WYSIWYG intermediary. The textarea ID is `#jform_articletext`. An automation can directly set `document.querySelector('#jform_articletext').value = '[html string]'` — but must also trigger the change event for Joomla's form validation to recognize the update.

6. **Template Style `- Use Default -`** means the system default template is applied. For city pages, this appears to be the intended state. If "CLEAN TOP 2026" needs to be assigned explicitly, the select control uses a searchable dropdown (likely Select2 or Chosen) that requires a click + type sequence, not a simple `<select>` value change.

7. **Module positions in content.** The article uses `{loadposition imageblock}` and `{loadposition Flowchart}` — these are Joomla module position shortcodes. They are NOT in the textarea; they ARE in the article content. The modules assigned to these positions are managed separately under Extensions → Modules.

8. **Joomla version is 3.9.26** — this is end-of-life Joomla 3.x. The admin interface differs significantly from Joomla 4/5. All selectors and workflows documented here are specific to J3.

9. **`advportfoliopro` cache group** (1.55 MB) is also in cache — this appears to be a portfolio/testimonials plugin. Clearing only the `page` group may be sufficient for city page updates.

10. **GSD (Google Structured Data) uses an iframe modal.** The `#gsdModal` iframe complicates automation. Selectors inside the modal must be accessed through the iframe document context, not the parent document.

## PART 1 vs PART 2 SPLIT

### PART 1 — Page/Meta Setup (Menu Item screens)
**Can be completed BEFORE the HTML content file exists? YES**, with one caveat: the Menu Item's "Select Article" field requires an article to exist first (you need the article ID). But the article can be created as a stub (empty content + title/alias/meta) to get the ID, then Part 1 can proceed, and Part 2 fills in the HTML content.

**Part 1 steps:**
- Step 1: Locate/search the menu item
- Step 2: Open menu item → Details tab (Menu Item Type, Select Article, Template Style)
- Step 3: Options tab (Show Title)
- Step 4: Page Display tab (Browser Page Title — NOTE: see Gotcha #3)
- Step 5: Metadata tab (Menu item meta — currently unused; skip)
- Step 6: Save (Menu Item) — toolbar

### PART 2 — HTML + Schema + Content (Article editor)
**Requires the HTML content file to exist before execution.**

**Part 2 steps:**
- Step 7: Open article editor via "Edit" button or direct URL
- Step 8: Content tab — paste/replace HTML in textarea (`#jform_articletext`)
- Step 9: Article Options tab (Show Title)
- Step 10: Google Structured Data tab (click "+ Add Structured Data", handle iframe modal)
- Step 11: Article Publishing tab — set Meta Description (THIS is where live meta description lives)
- Step 11b: Save article

### PART 3 — Cache & Verify
- Step 12: Clear cache (`com_cache` → Delete All or select `page` group → Delete)
- Step 13: Visit `https://www.stselectronicrecyclinginc.com/billings-mt` to verify

**Recommended split point:** After stub article creation → Part 1 completes menu item setup → HTML file arrives → Part 2 fills article content + meta → Part 3 cache + verify.

## GOTCHAS (Fragile/Non-Obvious for Automation)

| # | Gotcha | Impact |
|---|---|---|
| G1 | **`<title>` tag NOT controlled by "Browser Page Title" field** (empty for Billings; title comes from unknown plugin/template) | High — need to identify and automate the correct SEO title field |
| G2 | **Meta description lives in ARTICLE Publishing tab**, not Menu Item Metadata tab | High — writing to menu item meta does nothing on live page |
| G3 | **"Edit Article" opens a modal/iframe**, not a new page | Medium — automation must switch to iframe context; better to use direct article URL |
| G4 | **Template Style dropdown is a searchable Select2 control** — not a plain `<select>` | Medium — requires click + type + select sequence |
| G5 | **Google Structured Data uses a nested iframe (#gsdModal)** | Medium — double iframe context for schema entry |
| G6 | **Menu alias ≠ Article alias** (billings-mt vs billings) | Medium — don't confuse the two when constructing URLs |
| G7 | **Article editor is "No Editor" (plain textarea)**, not TinyMCE/JCE | Medium — setting value via JS must trigger change event for form validation |
| G8 | **Check-out lock icon** — if session crashes mid-edit, item locks; need Global Check-in before retry | Medium |
| G9 | **Cache `page` group = 28 MB** — clearing it may cause a brief site slowdown as pages re-cache | Low |
| G10 | **Joomla 3.9.26 is EOL** — JS/CSS selectors and form structure differ from J4/J5 | Background context |
| G11 | **New article requires creating article FIRST to get ID**, then linking from menu item | Process order matters |
| G12 | **Module position shortcodes** `{loadposition imageblock}` etc. must be preserved in content HTML | Content integrity |
| G13 | **State menu dropdown in menu items list has an in-dropdown search box** — automation must type inside the dropdown, not the main search box | Selector precision |
