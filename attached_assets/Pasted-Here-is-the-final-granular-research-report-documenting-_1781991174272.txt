GOTCHAS FOR VISUAL AUTOMATION
Strict Single Entry Constraints: JoomSEF features no batch, comma-separated, or multi-line loading layout windows inside the Manage 301 Redirects screen. To process all 4 requirements needed for a single renamed page (e.g., full path, short base slug, full path + /amp, short slug + /amp), an orchestration agent must cleanly loop 4 distinct times, running the full sequence loop: Click New → Populate Fields → Click Save & Close.

Leading Slash Uniformity: The interface defaults to relative site paths without leading slashes. Ensure your automated strings trim the preceding slash character (e.g., enter my-old-slug instead of /my-old-slug) to match how JoomSEF parses addresses internally.

Dynamic Tooltips: Form instructions and clues are tucked behind hover-triggered blue info symbols (i). If a script relies on reading instructions from the DOM dynamically, it must target or hover over these elements first.

Cache Sync Requirements: Saving metadata inside JoomSEF writes directly into database tables, but live routing tables may lag due to the JoomSEF server-side cache layer. If live verification breaks post-automation, adding a clear-cache routing step may be required.
