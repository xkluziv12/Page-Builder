#### Summary of Operation A workflow

1. Navigate to `Manage SEF URLs` (sidebar)
2. In `filterSEF` text box, type the city name (e.g. `billings`) and press Enter
3. Click the blue slug link in the SEF URL column (e.g. `billings-mt`) — **full-page navigation, not a modal**
4. If the URL tab is not already open (shown as the active/expanded panel), click the **URL** tab header
5. The **New SEF URL** field (`name="sefurl"`) shows the current slug — clear it and type the new short slug. **No leading slash.**
6. Set **Save as Custom Redirect** to **Yes** (radio `id="customurl1"`) to auto-create a 301
7. Click **Save & Close** (top-left green button)

**Page title (browser tab):** `301 Redirect: [ New ] — [site name] — Administration`
**Page heading (H1 in blue bar):** `301 Redirect: [ New ]` (or `[ Edit ]` when editing)
**Form action:** `administrator/index.php` (POST)

#### Toolbar buttons

| Button | Type | Color |
|---|---|---|
| **Save & Close** | `<button>` | Green with checkmark |
| **Cancel** | `<button>` | Red X |

#### Form section header

A grey bar labelled **URL** spans the full width above the two fields.

#### All fields — complete

| Field label | HTML `name` | Control type | Placeholder | Notes |
|---|---|---|---|---|
| **Moved from URL** | `old` | `<input type="text">` | *(empty)* | SOURCE / old path. **No leading slash.** Enter the slug exactly as it appears in the browser address bar, minus the domain. |
| **Moved to URL** | `new` | `<input type="text">` | *(empty)* | DESTINATION / new path. **No leading slash.** Enter the target slug only. |

#### Redirect type selector

**There is NO redirect type dropdown on this form.** All entries in this manager are implicitly 301 Moved Permanently. The component name ("301 Redirects Manager") and the info banner confirm this. There are no options for 302, 307, or any other type.

#### Hidden fields (identify what is being saved)

| `name` | value |
|---|---|
| `option` | `com_sef` |
| `controller` | `movedurls` |
| `task` | *(empty, set on submit)* |
| `id` | `0` (new) |

#### Confirming the 4-redirect-per-page pattern

The form is **single-entry only** — one "Moved from" → one "Moved to" per submit. There is no batch entry UI. All four redirects for a renamed page must be added as four separate round-trips through this form:

| Redirect # | Moved from URL (no leading slash) | Moved to URL (no leading slash) |
|---|---|---|
| 1 | original full path (e.g. `old-city-name-mt/areas-of-service/city-name`) | new short slug (e.g. `city-name-mt`) |
| 2 | short base slug (e.g. `old-city-name-mt`) | new short slug (e.g. `city-name-mt`) |
| 3 | original full path + `/amp` | new short slug |
| 4 | short base slug + `/amp` | new short slug |

This matches the live data pattern confirmed in the list (rows 6–8 for degaussing-dallas, rows 9–11 for Houston).

## GOTCHAS

**1. Tab state is sticky (most critical gotcha for Operation A).** The SEF URL edit form uses a `<dl class="tabs">` accordion structure. The open/closed state of each panel persists from the last visit via session. When the edit form opens, it will land on whichever tab was last active — which may be Aliases, Meta Tags, SiteMap, or Internal links. A visual agent MUST explicitly click the **URL** tab header before attempting to interact with the `sefurl` field. The URL tab `<dt>` has CSS class `tabs url-panel`; when closed it also has class `closed`, when open it has class `open`.

**2. Clicking the SEF URL slug causes a full-page navigation, not a modal.** The slug links in the list use `href="javascript:void(0);"` but trigger a standard page load to the edit form. There is no lightbox, modal, or inline editing. Wait for the full page to load before interacting.

**3. ViewMode filter must be correct.** The SEF URLs list has a `viewmode` dropdown. The URL `viewmode=3` = "Show All Redirects" which shows both SEF URLs and custom redirect entries. To see only canonical SEF URLs (the ones you'd edit to shorten slugs), set viewmode to `0` ("Show SEF URLs"). The filter at `viewmode=3` is the default direct URL but may show unexpected rows when searching.

**4. Leading slash rule — both forms, no leading slash, ever.** Both the `sefurl` field (Operation A) and the `old`/`new` fields (Operation B) store paths without a leading slash. Confirmed by live data: existing values are `billings-mt` not `/billings-mt`, and `2026-e-waste-regulations-.../blog/...` not `/2026-e-waste...`. Entering a leading slash will likely create a broken redirect.

**5. No redirect type selector — always 301.** The "Manage 301 Redirects" manager only creates 301 Moved Permanently redirects. There is no dropdown to choose 302 or other types. If a different redirect type is ever needed it cannot be done through this UI.

**6. "Save as Custom Redirect" on the SEF URL edit form auto-creates the 301.** When shortening a slug via Operation A, setting this radio to Yes will auto-generate a redirect entry in the 301 Redirects Manager from the old slug to the new one. However this only creates one redirect (the old primary slug → new slug). The other three redirects of the 4-redirect set (full path, /amp variants) still need to be added manually via Operation B.

**7. The 301 Redirects form shows only 2 fields — do not look for more.** A visual agent should not wait for or search for a redirect type selector, status toggle, or any other field on the New/Edit 301 form. The form has exactly two text inputs (`old` and `new`) plus Save & Close / Cancel buttons. Nothing else.

**8. Batch entry does not exist.** All four redirects per renamed page must be submitted one at a time. Each requires: click New → fill Moved from URL → fill Moved to URL → click Save & Close → repeat.

**9. Pagination default is 20 rows.** The SEF URLs list shows 20 rows by default. If searching without a filter on a large site, results will paginate. Use the `filterSEF` search box to narrow results to the specific city page before attempting to click an entry.

**10. "Moved to URL" can be empty on existing entries.** Live data shows row 12 (`accurate-electronics-carbon-footprint-calculator/`) has an empty "Moved to URL" column. This is valid — it appears to be a redirect to the site root or a catch-all. A visual agent should not assume both fields are always populated when reading the list.

**11. The component is internal-SEF-only.** The info banner on the 301 Redirects Manager explicitly states it only works for internal SEF-to-SEF URL redirects. It cannot redirect from a non-SEF URL to a SEF URL, and cannot redirect between domains.

**12. Cache after save.** After saving either an edited SEF URL (Op A) or a new redirect (Op B), the changes are live but JoomSEF's internal cache may still serve old URLs for cached pages. The bulk action "Copy to cache" or "Update URLs" in the SEF URLs list toolbar can be used to force a cache refresh, but this is a separate step and requires selecting rows and clicking Proceed.
