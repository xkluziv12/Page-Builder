# Joomla Publishing System Documentation for STS

This document provides a highly structured, step-by-step documentation of the Joomla administrative publishing system workflow for `stselectronicrecyclinginc.com`, using the **Billings, MT** city page as the live worked example.

---

## === PART 1: PAGE & META SETUP ===

**Target Start URL:** `https://www.stselectronicrecyclinginc.com/administrator/index.php?option=com_menus&view=items&menutype=mainmenu`

### 1. Finding the Page (Two Methods)

#### (a) Search Filter Method

* **Action:** Locate the search text field at the top-left of the items list view.
* **Control Label:** None (Placeholder text typically reads `"Search"` or `"Filter"` with a magnifying glass icon).
* **Control Type:** Text Input Field with an attached "Search" submit button.
* **Procedure:** Type `Billings` into the field and press Enter or click the magnifying glass button.
* **Expected State/Result:** The data grid filters dynamically to show rows matching the string.

#### (b) State Filter Dropdown Method

* **Action:** Locate the filter dropdown parameters on the right or top-right side of the filter bar.
* **Control Labels / Types:**
* `Select Status` (Dropdown) — Options: *Published / Unpublished / Trashed / Archived / All*.
* `Select Max Levels` or `Select Parent` (Dropdown) — Hierarchical level grouping selector.
* `Select Access` (Dropdown) — Options: *Public / Guest / Registered / Special / Super Users*.


* **Grouping Behavior:** Menu items are grouped hierarchically under parent items (e.g., Parent menu item: "Montana" or "States"). To locate Billings manually, use the parent layout structure or filter by parent state rules.
* **List Columns Recorded:** * `Checkbox` (Selection box)
* `Status` (Icon: Green checkmark for Published, Red circle for Unpublished)
* `Title` (Text link, contains the visible menu string)
* `Alias` (Text string displaying the SEF URL segment)
* `Access` (Text indicating view level, e.g., *Public*)
* `Association` / `Language` (Text/Icon, e.g., *All*)
* `ID` (Integer numeric marker on the far right)


* **Alias Rules:** The Alias column displays exactly `billings-mt`. The confirmed naming convention is exclusively `[city-lowercase]-[statecode-lowercase]`.

## === EXPLORE & SYSTEMIZE (TRIBAL KNOWLEDGE) ===

### 14. Global Navigation Matrix

* **Admin Base:** `https://www.stselectronicrecyclinginc.com/administrator/`
* **Primary Structural Pathways:**
* *Menus Menu:* `Menus -> Main Menu`
* *Content Engine:* `Content -> Articles`
* *Performance Controls:* `System -> Clear Cache`



### 15. Naming Frameworks and Page Clones

* **Hierarchy Location:** All localized service footprints exist as direct root-level child nodes inside the `Main Menu` tree rather than nested cascading children, ensuring flat, optimized URL pathways (`/billings-mt` instead of `/montana/billings`).
* **New Location Provisioning Workflow:** To establish a new location reliably:
1. Open the existing **Billings** menu profile.
2. Click **Save as Copy** to preserve configurations.
3. Revise Title, Alias (`newcity-statecode`), and update the target text pointer fields.



### 16. Absolute Asset URL Quirks

* **Verification Note:** Images embedded in content **MUST use absolute paths** (`https://www.stselectronicrecyclinginc.com/images/...`) instead of root-relative paths (`/images/...`). Joomla's SEF URL routing engine frequently breaks relative asset lookups on clean virtualized paths, causing broken imagery errors on localized front-end targets.

### 17. Critical Automation Architecture Notes

* **Session Lifespans:** The administration session timeout threshold is aggressively enforced. Idle browser sessions will experience automatic logouts after a set window (~15–30 minutes). Automation frameworks should cache cookies or retain session persistence state profiles dynamically.
* **Asynchronous Content Rendering:** Frame changes and article modals load script files asynchronously. Interceptors must deploy explicit wait loops watching for element target lookups rather than arbitrary static sleep intervals.

## PART 1 vs PART 2 SPLIT

The optimal point to split browser agent execution is at **Step 7**.

* **Part 1 (Steps 1–6):** Focuses entirely on structural validation, shell menu orchestration, metadata binding, and template layout selection. **Part 1 can be successfully completed before the standalone content asset file is completely processed**, provided a target article identifier placeholder exists.
* **Part 2 (Steps 7–11):** Focuses on deep text buffer payload manipulation, structural code view switching, script content injection, and validation logic inside the underlying content block.

---

## GOTCHAS (Automation Warning Profiles)

1. **Asynchronous Text Area Switches:** Swapping the editor context from standard text mode into the raw monospaced HTML layout engine requires explicit element validation checks before pushing code data frames.
2. **Hidden Selection Modals:** Linking a menu configuration record to an explicit core article content target utilizes an iframe popup selector map. System code layers must catch window refocus tasks fluidly.
3. **Session Interruption Handling:** System-wide cache clearing sweeps or processing latency stalls can invalidate access headers randomly. Keep authentication re-entry blocks standard.
